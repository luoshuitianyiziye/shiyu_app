## 1. 一句话认识这个项目

「时屿」是一个**日程管理 + 番茄钟 + 笔记**三合一的效率 App，用 Flutter 开发，可以同时运行在安卓、苹果、鸿蒙三个平台上。它最大的特色是**游戏化的成长激励**：每完成一个任务就获得经验值，经验值升级、升级解锁段位（雾芽 → 浅湾 → 青屿……→ 时屿），每个段位解锁一幅漂亮的插画，像集邮一样让人愿意坚持使用。

设计风格叫「莫兰迪色系」，整体是淡雅、柔和的雾绿色调。

## 2. 技术栈总览（用到的所有技术）

### 2.1 开发框架：Flutter

Flutter 是谷歌出品的**跨平台开发框架**。它最大的特点是：**写一份代码，能同时编译成安卓、苹果、鸿蒙的原生应用**。原理是 Flutter 自带一个高性能的绘图引擎（叫 Skia/Impeller），不依赖系统控件，自己把每一个界面元素画出来，所以三个平台看起来完全一致。

### 2.2 编程语言：Dart

Flutter 用的语言叫 Dart（项目版本 3.13）。它语法和 Java/C# 有点像，容易上手。本项目所有逻辑代码都用 Dart 编写。

### 2.3 状态管理：flutter_riverpod

App 里有大量「数据变了，界面要跟着变」的场景（比如完成任务后经验条要动）。Riverpod 是一个状态管理库，它把「数据」和「界面」绑定起来：数据一变，用到它的界面自动刷新。项目里每个页面「盯着」自己需要的数据，不需要手动通知刷新。

### 2.4 页面路由：go_router

App 里有很多页面（登录页、今日页、笔记编辑器……），从一个页面跳到另一个页面叫「路由」。go_router 是管理跳转的库，还能做「跳转拦截」——比如没登录就强制先去登录页。

### 2.5 本地数据库：drift（SQLite）

App 的所有数据（任务、事件、笔记、经验……）都存在手机本地。drift 是一个数据库库，底层用的是 SQLite（手机系统自带的轻量数据库）。drift 让我们可以用写代码的方式操作数据库，不用手写 SQL 语句。它还支持**自动生成代码**（`database.g.dart`），保证类型安全。

### 2.6 本地通知：flutter_local_notifications + timezone

App 要在指定时间弹系统通知（如「任务开始啦」「事件要到了」）。这个库负责安排和发送通知。timezone 库处理时区，保证提醒时间准确。

### 2.7 音频播放：just_audio

专注页要播放白噪音（雨声、海浪……）。just_audio 负责播放、暂停、循环音频。

### 2.8 富文本编辑器：flutter_quill

笔记页是一个功能完整的文字编辑器（加粗、斜体、列表、图片……）。flutter_quill 是成熟的富文本编辑器组件。

### 2.9 图片处理：image_picker + flutter_image_compress

从相册选图用 image_picker；选完自动压缩（手机照片很大，压缩后存储省空间）用 flutter_image_compress。

### 2.10 文件选择：file_picker

上传自定义白噪音音频时，弹出系统文件选择器选音频文件。

### 2.11 滑动操作：flutter_slidable

今日任务的「左滑出编辑/删除按钮」「右滑直接完成」就是它实现的——列表项可以向左/右滑动露出操作。

### 2.12 本地设置存储：shared_preferences

像「用户昵称」「上次选的主题」这类小数据，用 shared_preferences 存（本质是手机上的一个小配置文件）。

### 2.13 其他工具库

| 库 | 作用 |
|---|---|
| path_provider | 找到手机应用专属的存储目录（存图片、音频） |
| path | 拼接文件路径（跨平台格式统一） |
| intl | 日期格式化（显示「8月18日」这种中文日期） |
| flutter_timezone | 获取手机当前时区 |
| cupertino_icons | iOS 风格图标 |

### 2.14 开发辅助工具

| 工具 | 作用 |
|---|---|
| build_runner + drift_dev | 根据数据库表定义自动生成类型安全的代码 |
| flutter_lints | 代码规范检查（保证代码质量） |
| flutter_test | 自动化测试框架 |

### 4.1 「features」里的统一套路（重要概念）

每个功能模块内部又分两个子文件夹，这是 Flutter 社区推荐的「干净架构」风格：

- `data/`：**数据层**——只管数据怎么来（比如「白噪音有哪些」「经验怎么算」）
- `presentation/`：**界面层**——只管界面长什么样（页面、弹窗）

这样分层的好处：改界面不动数据，改数据不动界面，互不干扰。

## 5. 核心机制逐个讲（小白也能懂）

### 5.1 应用启动流程（main.dart）

打个比方：App 启动就像「开门营业前的一系列准备」。

1. **准备环境**：`WidgetsFlutterBinding.ensureInitialized()` —— 让 Flutter 先把自己初始化好
2. **准备中文**：`initializeDateFormatting('zh_CN')` —— 加载中文日期格式（否则日期显示英文）
3. **读取小配置**：从手机配置文件里读「上次登录的昵称」（`shared_preferences`）
4. **打开数据库**：`AppDatabase()` —— 连接手机里的 SQLite 数据库文件
5. **初始化通知服务**：`NotificationService.instance.init()` —— 创建通知渠道、请求通知权限
6. **读取设置**：从数据库读番茄时长、收尾提醒时间等
7. **滚动重复任务**：把「每天/每周」重复的任务复制到今天（比如你设了「每天背单词」，今天打开就会自动出现）
8. **安排收尾提醒**：预约今天 21:30 的「还有任务没完成」提醒
9. **启动界面**：`runApp(...)` —— 把整个 App 画到屏幕上
10. **跨午夜守护**：启动一个每分钟检查一次的定时器，如果跨过了午夜（0 点），自动刷新日期、滚动新一天的任务

### 5.2 昵称登录与页面导航（auth + router）

- 登录页就是一个输入框 + 一个按钮：输入昵称 → 存到手机配置 → 进入主界面
- 路由（router.dart）里配置了一条规则：**昵称为空就强制去登录页，有昵称才能进主界面**。这就是「登录拦截」。
- 退出登录 = 清掉昵称 → 路由自动把用户弹回登录页

### 5.3 数据是怎么存起来的（database.dart）

App 有 **8 张表**，就像 Excel 里的 8 张工作表：

| 表名 | 存什么 | 例子 |
|---|---|---|
| users | 用户 | 昵称、经验、等级、段位、连胜天数 |
| tasks | 任务 | 标题、四象限、难度、时段、是否完成 |
| xp_logs | 经验流水 | 「+30 XP：完成任务「写作业」」 |
| events | 事件 | 标题、日期、时间、提前提醒分钟 |
| notes | 笔记 | 标题、富文本内容、图片、分类 |
| note_categories | 笔记分类 | 分类名、颜色 |
| settings | 设置 | 番茄时长、收尾提醒时间、主题 |
| pomodoro_sessions | 番茄记录 | 每次专注的分钟数（用于统计） |

**数据库版本管理**：数据库结构改版（比如加一列）时，版本号 +1（现在到 v7），并写「迁移脚本」把老用户的旧数据平滑升级到新结构，数据不丢。

### 5.4 五页签主界面（home_shell.dart）

底部 5 个页签：**今日 / 专注 / 日历 / 笔记 / 我的**。点哪个显示哪个页面，其他页面保持原样不重新加载（用 `IndexedStack` 技术，切换无延迟）。按系统返回键时先弹「确定退出吗」确认框，防止误退。

### 5.5 今日任务：四象限 + 完成得经验（today_page.dart）

- **四象限**：把任务分成「重要紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急」四类，用四种颜色区分
- **创建任务**：弹出底部窗口，填标题、选象限、选难度（简单/普通/困难）、可设开始时段（滚动时间选择器）、可设重复规则（不重复/每天/工作日/每周）
- **完成任务**：三种方式都行——①点任务左边的圆圈 ②右滑到底（手势完成）③点完成区
- **完成后的连锁反应**（代码里是核心事务）：
  1. 任务标记为已完成
  2. 计算经验（基础 10 分 × 难度系数 × 象限系数）
  3. 经验加给用户，流水写入 xp_logs
  4. 等级/段位重新计算（可能触发「晋段庆祝弹窗」）
  5. 连胜天数结算（昨天完成过就 +1）
  6. 取消这个任务的「开始提醒」（已完成不用提醒了）
- **已完成区**：完成的沉到底部，支持多选「恢复」或「彻底删除」
- **防连点**：快速点 N 次只结算一次经验（事务内重读任务状态），避免刷经验

### 5.6 成长体系：经验 → 等级 → 段位 → 解锁插画（growth）

- **经验公式**：升到 L 级需要 50 × L × (L+1) 经验（越往后越难）
- **段位**：每 5 级晋升一段，共 9 段：雾芽 → 浅湾 → 青屿 → 竹林 → 松风 → 远山 → 星河 → 沧海 → 时屿
- **段位墙**：9 个格子，未解锁的显示灰色锁；解锁后展示精美插画
- **晋段庆祝**：段位提升瞬间弹出全屏庆祝弹窗
- **成就系统**：8 个成就（完成 1 个任务、完成 100 个任务、连续 7 天、累计 10/50/100 个番茄……），带进度条
- **统计页**：累计番茄数、专注时长、本周数据、最近 7 天柱状图

### 5.7 专注页：番茄钟 + 白噪音（focus_page.dart）

- **番茄钟**：专注 25 分钟 → 短休 5 分钟 → 专注 → 短休……每 4 轮来一次长休 15 分钟
- **倒计时**：每秒跳动（Timer.periodic），时间到自动切换阶段
- **跳过**：可以跳过当前阶段（跳过不结算经验、不推进轮次）
- **白噪音联动**：开始计时 → 自动播放白噪音；暂停 → 白噪音暂停；继续 → 恢复。5 种内置音效（雨声/海浪/篝火/风声）或上传自己的音频
- **完成奖励**：每完成一个番茄 +5 XP
- 所有计时器、音频播放器用完都正确释放，避免内存泄漏

### 5.8 日历：事件提醒 + 倒数日（calendar_page.dart）

- **月视图**：翻页看日历，有事件的日子显示小圆点，今天高亮
- **添加事件**：名称 + 日期 + 可选具体时间 + 提前提醒（准时/15 分/30 分/1 小时/1 天）
- **提醒计算**：比如事件 14:30、提前 15 分钟 → 14:15 弹通知；如果提前提醒时刻已过但事件还没到，改成 1 分钟后提醒（保证不丢提醒）
- **倒数日视图**：切换页签，显示「还有 N 天」，3 天内红色警示，今天显示「就是今天 🎉」
- 左滑事件 → 编辑/删除

### 5.9 笔记：富文本 + 图片（notes_page.dart + note_editor_page.dart）

- **编辑器**：标题 + 正文。正文是富文本：加粗、斜体、下划线、删除线、字体颜色、列表、待办清单（勾选后文字自动加删除线）
- **图片**：从相册选图 → 自动压缩（最长边 1600px）→ 存到应用专属目录 → 插入笔记。点图片可查看大图、加文字说明、删除
- **分类**：自定义分类（每个分类有颜色），笔记可归类
- **搜索**：按标题或正文关键词过滤
- 图片文件管理很讲究：删除笔记会清理对应图片文件，避免垃圾文件堆积

### 5.10 设置与主题换肤（settings_page.dart + morandi_theme.dart）

- **主题**：6 套莫兰迪配色（雾绿默认、玫瑰、雾蓝、燕麦、紫藤、墨夜），即选即生效并记忆
- **番茄时长**：专注/短休/长休分钟数可调
- **收尾提醒时间**：默认 21:30，可改，改完自动重新安排系统通知
- **默认白噪音**：专注开始自动播放哪个音效，可选「不自动播放」

### 5.11 通知提醒系统（notification_service.dart）

三类提醒，各用不同编号段（避免互相覆盖）：

| 提醒 | 编号范围 | 说明 |
|---|---|---|
| 任务开始提醒 | 100000+ | 任务设了时段，到点提醒 |
| 事件提醒 | 200000+ | 事件按提前量提醒 |
| 每日收尾提醒 | 999001 | 每天固定时间提醒「还有任务没完成」 |
| 番茄完成通知 | 888001 | 专注结束的即时通知 |

通知用「时区 + 精确时刻」调度，安卓上配了开机自启接收器（重启手机后提醒依然有效）。

### 6.1 完成任务并结算经验（核心事务）

```dart
Future<({int xp, int oldRank, int newRank})> completeTaskAndAwardXp(TaskRow task) async {
  await transaction(() async {            // ① 开事务：要么全部成功，要么全部回滚
    final current = await ...重读任务最新状态...;
    if (current == null || current.isDone || current.deleted) {
      skipped = true;                     // ② 防连点：已完成/已删除 → 跳过
      return;
    }
    xp = taskXp(difficulty: ..., quadrant: ...);  // ③ 按最新配置算经验
    await ...标记任务完成 + 写经验流水...;
    // ④ 连胜结算 + ⑤ 经验加到用户 + ⑥ 重算等级/段位
  });
  return (xp: xp, oldRank: oldRank, newRank: newRank);
}
```

**给小白解释**：数据库「事务」就像银行的转账——要么钱转成功，要么一分不动，绝不会出现「钱扣了但没到账」。这里保证「标记完成 + 加经验 + 升级」是一个整体。

## 8. 常见问题与已修复的坑

项目开发过程中踩过并解决了不少坑，记录下来给新手参考：

1. **flutter_quill 插入图片不独占一行**：删图会连带删掉同行文字 → 插入前把光标挪到行首
2. **连点刷经验**：事务内重读任务状态，重复完成返回 0 经验
3. **「（共 N 项）」奇怪提示**：普通提示不进合并窗口，只有经验提示按来源合并
4. **主题亮度判断反了**：按文字亮度判断深浅导致浅色主题被当深色 → 改为按背景亮度
5. **右滑完成卡住**：flutter_slidable 的阈值参数需要配合（openThreshold 设为接近 1 永不自动打开）
6. **Android 通知权限**：Android 13+ 需运行时申请通知权限 + 精确闹钟权限
7. **音频 20MB → 5.8MB**：白噪音截取 75 秒片段 + 首尾淡入淡出无缝循环 + 压缩编码
8. **段位图 67MB → 1.2MB**：超大原图压缩到 1600px、转 WebP
9. **iOS 通知 64 条上限**：未来计划做滚动窗口（当前 iOS 构建搁置）
